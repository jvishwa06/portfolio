# Portfolio

A minimal developer portfolio website with a blog and a products section, built with Next.js. Live at [jvishwa.me](https://jvishwa.me).

## Features

- **Profile, blog and products** sections, organised under `src/features/profile`, `src/features/blog` and `src/features/products`.
- **MDX content** rendered with `next-mdx-remote` and `fumadocs-core`.
- **Command menu** (`cmdk`), light and dark themes (`next-themes`), and animations with `motion` / `framer-motion`.
- **Site files generated by the app**: `sitemap`, `robots`, an RSS feed (`/rss`), Open Graph images (`/og`), a web app manifest and a downloadable vCard (`/vcard`).
- **Vercel Analytics** and **Speed Insights**.

## Tech stack

Next.js 16, React 19, TypeScript, Tailwind CSS 4, shadcn/ui components, Zod, SWR, Geist font and Lucide icons.

## Project layout

```
src/
  app/          Routes and layouts (including og, rss, sitemap, vcard)
  components/   Shared and UI components
  config/       Site info and navigation (site.ts)
  features/     profile, blog and products
  lib/          Fonts, MDX/rehype/remark helpers and utilities
```

## Run locally

The repo uses pnpm. The Node version is in `.nvmrc`.

```bash
pnpm install
pnpm dev          # http://localhost:1408
```

Other scripts: `pnpm build`, `pnpm start`, `pnpm lint`, `pnpm check-types`.

The site URL can be changed with the `APP_URL` environment variable.
